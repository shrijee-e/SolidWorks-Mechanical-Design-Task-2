# Exercise 3 – Sheet-Metal Enclosure

## Objective

The objective of this exercise was to create a sheet-metal enclosure using
SOLIDWORKS sheet-metal features and generate its flat pattern for fabrication.

## Work Completed

A bent sheet-metal enclosure was created from a base profile and multiple
flanges.

The finished model was also converted into a flat pattern to understand how
the formed component can be manufactured from a single sheet.

## Features Practiced

- Base Flange
- Edge Flange
- Sheet-Metal Parameters
- Bend Allowance
- Bend Radius
- Corner Relief
- Hole/Cut features
- Hem / sheet-metal edge features
- Flat Pattern

## Manufacturing Consideration

The model was developed with sheet-metal manufacturing in mind. The flat pattern
provides the developed geometry before bending.

## Key Learning

This exercise improved understanding of:

- Sheet-metal design
- Bend allowance
- Bend radius
- Manufacturing-oriented modelling
- Flat-pattern generation
- Designing parts that can be produced from sheet stock
