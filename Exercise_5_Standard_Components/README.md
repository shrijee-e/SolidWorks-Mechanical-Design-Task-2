# Exercise 5 – Mechanical Gear Assembly

## Objective

The objective of this exercise was to create and assemble mechanical components
to understand assembly modelling and component relationships in SOLIDWORKS.

## Work Completed

A mechanical gear-and-shaft assembly was created using individual components
and assembly mates.

The assembly includes gear components, a shaft and supporting components.

## Components

- Gear
- Shaft
- Supporting/Bearing component
- Additional mechanical components as required by the assembly

## Features Practiced

### Part Modeling
- Extruded Boss/Base
- Extruded Cut
- Revolved geometry
- Circular features
- Gear geometry

### Assembly Modeling
- Insert Components
- Coincident Mate
- Concentric Mate
- Distance/positioning mates
- Component alignment
- Assembly organization

## Assembly Objective

The components were positioned so that the shaft and gear system form a
functional mechanical assembly.

## Key Learning

This exercise improved understanding of:

- Mechanical component modelling
- Assembly creation
- Mating components
- Component alignment
- Mechanical design relationships
- Designing parts that work together as an assembly

## Software

SOLIDWORKS 2026

## Files

- `.SLDASM` – Final assembly
- `.SLDPRT` – Individual component parts
