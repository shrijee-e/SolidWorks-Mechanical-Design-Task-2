# Exercise 4 – Structural Frame / Weldment

## Objective

The objective of this exercise was to create a structural frame using
SOLIDWORKS Weldments and Structural Member features.

## Work Completed

A structural framework was created using sketch geometry as the basis for
structural members.

The model demonstrates how multiple members can be created and organized
within a single weldment structure.

## Features Practiced

- 2D/3D Sketching
- Structural Members
- Weldment profiles
- Member positioning
- Trim and extend operations
- Structural frame construction
- Weldment feature organization

## Manufacturing Consideration

The design represents a fabricated structural assembly where individual
members can be cut, positioned and joined to form a complete frame.

## Key Learning

This exercise provided practical experience with:

- Structural frame modelling
- Weldment-based design
- Member placement
- Joining structural members
- Designing with standard structural profiles
