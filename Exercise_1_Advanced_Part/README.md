# Exercise 1 – SOLIDWORKS Basic Modeling

## Objective

The objective of this exercise was to practice the fundamentals of 3D part modeling in SOLIDWORKS.

## Work Completed

The part was created using standard SOLIDWORKS sketching and feature-based modeling tools.

### Features Practiced

- 2D Sketching
- Smart Dimensions
- Geometric Relations
- Extruded Boss/Base
- Extruded Cut
- Basic feature modification
- Design intent through properly defined sketches

## Skills Developed

- Understanding the SOLIDWORKS modeling interface
- Creating and modifying sketches
- Applying dimensions and relations
- Creating 3D geometry from 2D sketches
- Organizing features in the FeatureManager Design Tree

## Software

SOLIDWORKS 2026
