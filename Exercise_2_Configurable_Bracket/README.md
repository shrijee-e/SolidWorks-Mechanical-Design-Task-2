# Exercise 2 – Parametric Bracket and Design Table

## Objective

The objective of this exercise was to create a sheet/solid bracket and develop multiple
configurations using a SOLIDWORKS Design Table.

## Work Completed

A bracket was modelled using parametric features and then configured into different
size variants using a Design Table.

### Configurations Created

- Default
- Bracket Small
- Bracket Medium
- Bracket Large

## Features Practiced

- Sketching
- Smart Dimensions
- Extruded Boss/Base
- Extruded Cut
- Hole features
- Parametric modeling
- Design Table
- Configuration management

## Parametric Design

The Design Table was used to control dimensions and feature values for different
configurations.

This allows multiple versions of the same component to be generated without
creating separate part files.

## Key Learning

This exercise demonstrated how parametric design and configurations can reduce
design time and make a model easier to modify for different requirements.

## Software

SOLIDWORKS 2026

## Files

- `.SLDPRT` – Parametric bracket
- Design Table – Embedded within the SolidWorks part
